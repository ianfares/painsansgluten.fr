# Projet boutique « Mon Sans Gluten by Angélique » — dossier de cadrage

À placer à la racine du dépôt Git **avant** la première session Claude Code.

| Fichier | Rôle |
|---|---|
| `CLAUDE.md` | Règles permanentes lues par Claude Code à chaque session |
| `PLAN.md` | Document de référence V1 (fonctionnel, technique, avertissements, « À RENSEIGNER ») |
| `tasks/T00…T25` | Une fiche par tâche, dans l'ordre d'exécution |
| `CHECKLIST-PROD.md` | Recette et mise en production |

## Comment lancer Claude Code
1. Créer le dépôt privé, y copier ces fichiers, créer la branche `develop`.
2. Première instruction à Claude Code :
   > Lis CLAUDE.md et PLAN.md en entier. Résume-moi en 10 lignes ce que tu as compris et liste tes questions. N'écris aucun code avant ma validation.
3. Ensuite, tâche par tâche :
   > Exécute la tâche `tasks/T00-initialisation.md`. Respecte CLAUDE.md. Termine par le compte rendu au format prévu.
4. Relire le compte rendu, tester, merger dans `develop`, passer à la suivante.
5. Tâches **critiques** (T12, T14, T15, T16, T18, T23) : relecture attentive avant merge — idéalement demander à une seconde session Claude un audit de la branche avant de merger.

**Priorité absolue J1 : T01 (Chronopost).**
